# Data Ingestion, Cleaning & Preprocessing with Pandas

## Project Overview
This project focuses on cleaning and preprocessing a messy business dataset using Python and Pandas.

## Tasks Performed
- Loaded the raw business dataset
- Identified missing values
- Removed duplicate records
- Converted incorrect data types
- Handled outliers using IQR
- Performed feature engineering
- Extracted Year and Month from Order Date
- Calculated Profit Margin
- Exported the cleaned dataset

## Files
- `raw_dataset.csv` - Original messy dataset
- `clean_dataset.csv` - Cleaned dataset
- `data_cleaning_project.ipynb` - Jupyter Notebook
- `data_cleaning_project.py` - Python script
